VISUAL SYNTH GALLERY

OPEN GALLERY.cmd opens the local gallery.

EDIT FAVORITES.cmd opens the gallery list in Notepad.

favorites.txt controls which videos appear and their order. Put one exact MP4
filename on each line. A line beginning with # is ignored. After changing it,
run PUBLISH GALLERY.cmd. It makes lightweight website copies, saves the change
to GitHub, and updates the public gallery. GitHub Pages may take a minute or two
to show the new version.

UPDATE GALLERY.cmd refreshes only the local website copy and does not publish.
OPEN GALLERY.cmd opens that local copy for checking before you publish.

Your original renders are never changed or moved.
